# Кнопка BLE config mode

## Задача

Додати фізичну кнопку або інший input для wake/config режиму.

## Ціль

- Вмикати BLE advertising тільки за дією користувача.
- Поза BLE config mode повністю вимикати BLE advertising.
- Розблокувати перехід до глибшої економії енергії в idle-режимі.

## Контекст

Зараз BLE використовує fast advertising перші 5 хвилин після старту, після чого
перемикається на slow advertising і залишається доступним для підключення.
Після disconnect advertising запускається повторно в поточному режимі.

Вмикати light sleep без продуманої BLE-кнопки ризиковано: користувач може
втратити простий шлях до налаштування Wi-Fi/API через телефон.
