# Валідація GPIO для реле та датчиків протоку

## Задача

Додати перевірку пінів у налаштуваннях керування реле та зчитування датчиків
протоку. Довільні значення GPIO заборонити: використання системних пінів може
порушити роботу контролера.

## Вимоги

- Перевіряти пін реле за переліком GPIO, дозволених для керування реле.
- Перевіряти пін датчика протоку за окремим переліком GPIO, дозволених для
  зчитування датчиків протоку.
- Відхиляти значення, яких немає у відповідному переліку, до застосування
  налаштувань.

## Перед реалізацією

Конкретні переліки дозволених GPIO для кожного випадку будуть надані окремо
на момент реалізації задачі.
