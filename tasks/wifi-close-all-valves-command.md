# WiFi-команда закриття всіх клапанів

## Поточний стан

- WiFi API має команду ручного відкриття одного клапана через
  `POST /api/valves/open-for-time`.
- `Hypervisor` уже має внутрішній механізм `closeAllValves()` для аварійного
  закриття всіх клапанів.
- Окремої WiFi API-команди для ручного закриття всіх клапанів немає.

## Задача

- Додати WiFi API endpoint для закриття всіх клапанів.
- Використати наявну авторизацію WiFi API.
- Закривати всі відкриті клапани незалежно від того, чи вони були відкриті
  ручною командою, автоматичним поливом або захисною логікою.
- Оновити документацію для мобільного додатку після додавання endpoint.

## Очікуваний ефект

Користувач або мобільний додаток зможе швидко зупинити весь полив через WiFi
без очікування таймерів, порогів вологості або спрацювання захисної логіки.
